# ההרכב האולטימטיבי

משחק כדורגל אינטראקטיבי לשני שחקנים.

## מצבי משחק
- משחק ביחד על אותו מכשיר עם מסך מעבר שמסתיר את ההרכב.
- משחק אונליין עם חדר וקישור הזמנה, באמצעות WebRTC/Trystero.

## מה יש במשחק
- 12 מועדונים בגרסת הפתיחה.
- בחירת פורמציה: 4-3-3, 4-4-2, 3-5-2, 4-2-3-1.
- בחירת שחקני עבר והווה לפי שוער / הגנה / קישור / התקפה.
- אין אפשרות לבחור אותו שחקן פעמיים באותו הרכב.
- חישוב תוצאה לפי איכות הקווים, סינרגיה ורכיב אקראיות מתון.
- בתיקו ניתן לפתוח את ההרכבים, לשנות ולשחק שובר שוויון.

## דירוגים
ה-ratings הם דירוגי משחק פנימיים לצורכי סימולציה ובידור, לא דירוג היסטורי רשמי.

## מבנה
האפליקציה נמצאת כקובץ סטטי יחיד ב-`index.html`, כדי שניתן יהיה להריץ ולארח אותה בלי שרת אפליקציה.
